📘 课时表提醒 · 操作手册✕

📌这是一款什么工具

课时表提醒帮你管好每周课表，并在每节课前准时提醒；还能记下每一节课的课酬，自动算出累计实发工资。

它不用去应用商店下载，装到手机桌面就能当 App 用，数据只存在你自己的手机里，不用注册、断网也能看。

底部四个按钮：今日（今天的课 + 记账）、课表（排整周的课）、统计（图表 + 累计工资）、设置（提醒 / 微信 / 帮助）。

📲安装与激活

1
用手机浏览器打开应用 → 点右上角「分享」→ 选「添加到主屏幕」→ 桌面出现「课时表提醒」图标，点开即用。
2
第一次打开要填授权码（如 0001-A1B2C3）→ 点「激活并使用」。授权码会自动记住，以后不用再填。
一个授权码一人用：这是付费工具，每个授权码只对应一位使用者。只转发安装文件、没有授权码是打不开的。授权码丢了，找发给您的人补发即可。

➕添加 / 修改课节

在「课表」页，或点右下角「＋」添加一节课：填 星期（周一到周日）、第几节、起止时间、科目、班级、地点。

「课节属性」决定要不要填课酬：选正常就不填；选加班代课其他会多出「课酬 / 费用」一栏。点课节卡片可改，点「✕」可删。

正常课、加班课会算进"每周重复课表"和课时分布图；代课、其他算临时课，不进每周课表，但照样能记工资。

⏰设置上课提醒

在「设置」里调：提前几分钟提醒、响铃方式，以及要不要开横幅 / 声音 / 震动 / 系统通知。点「试一下提醒」能马上听到效果。每一节课也能单独设提前量。

提醒靠应用后台运行，应用保持打开才能到点响铃；装到桌面后震动和通知最稳。

💰记账与累计实发工资

课节按属性决定怎么算工资：正常没有工资；加班是每周固定重复课，系统按「每周加班薪 × 经过周数」自动累加，不用手点；代课其他是临时课，上完在「今日」页点橙色「记一笔 ¥X」才实时计入（再点取消，🗑 可删）。

「设置」里可改学期起始日（默认本周一），它决定"从第几周开始算"——过了几周，加班工资就自动翻几倍。

总工资 = 加班按周累加 + 代课实时 + 其他实时。正常课不计工资；加班是重复课自动算，不是逐节记；只有代课 / 其他需要你每节"记一笔"。

📊统计看板

本周课时分布：按星期显示每天几节课（共 N 节）。

薪酬统计：每周加班薪 / 加班累计(×N周) / 代课实时 / 其他实时，外加按属性累计的柱状图。

累计实发工资：总工资累计 / 本月实发 / 记账笔数，下面还有每一笔记账明细。累计实发请到「统计」页查看。

🔔微信推送（可选）

想让微信也收到提醒？在「设置 → 微信推送」打开开关，填一个 Server酱 SendKey（去 sctapi.ftqq.com 免费领）。每天固定时间（默认 08:00）会推当天全部课程，每节课前再分条推送。免费版每天最多 5 条。

❓常见问题

  • 收不到提醒？应用要保持打开；想用震动 / 通知最好先装到桌面；系统通知要点「开启系统通知」允许一下。
  • 换手机了？数据存在本机浏览器，换设备不会自动过去；但授权码可以在新手机上重新激活使用。
  • 改了课表，累计工资会变吗？不会，累计只认"记一笔"这一动作。
